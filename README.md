# ParkGrid

ParkGrid is a Flutter smart parking reservation app.

## Run the app

Install the Flutter SDK, then run these commands from the project directory:

```powershell
flutter pub get
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8443
```

Open `http://127.0.0.1:8443` in a browser. To run on an Android emulator, start an emulator and use `flutter run`.
